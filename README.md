# StaffChat

StaffChat gives your staff team a private communication channel without disrupting normal player chat.

Type a simple prefix before a message, and it is routed to staff members only.

## Why Server Owners Use It

- Keep moderation and support communication private
- Coordinate quickly without opening extra tools
- Reduce chat clutter while staying responsive in-game
- Let players report things naturally in chat while only staff sees it (optional)

## Core Features

- Prefix-based staff chat (default: `@`)
- Permission-based visibility for staff members
- Configurable plugin prefix and chat colors
- Clean, readable message format
- Reload support for fast configuration changes

## Example

- `@Check spawn, possible issue near market`

Only staff with receive permission will see the message.

## Setup

1. Drop `StaffChat` into your server plugins folder.
2. Restart the server.
3. Adjust the prefix and colors in the config if needed.

## Command

- `/staffchat reload` or `/sc reload`

## Perfect For

- Survival and SMP servers
- Network moderation teams
- Event and support staff
- Any community that needs fast, private in-game coordination
